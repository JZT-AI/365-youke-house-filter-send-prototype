# 365有客 APP：房源筛选与发送优化

有客 APP 交互原型，覆盖主营小区筛选与设置引导、小区名称／别名／板块查找、发送前房源更新及卡片发送反馈。含房源报告按通知继续发送，更新最多等待30秒，失败或超时仍使用可用内容发送。

- [在线预览](https://jzt-ai.github.io/365-youke-house-filter-send-prototype/)
- [原型入口](有客App/index.html)

房源管理和选择房源的“我的／全部房源”均提供独立主营小区筛选。右侧演示面板可切换主营小区已设置／未设置，以及房源更新、消息发送的不同场景。

原型使用本地示例数据和浏览器存储，不调用真实数据采集或客户消息服务。仓库仅包含有客 APP 原型及其运行资源。

部署使用 GitHub Pages：`main` 分支根目录，无需安装依赖或构建。

报告与素材的四张示例缩略图由 `有客App/app-media.js` 内置，来源为同目录的本地图片，独立于其他端原型和页面路径。
